## Что изменилось относительно v1 (итоги трёх трековых сессий 06–07.11)

1. **«Пилота» не будет — он уже был.** Сентябрьская кампания Директа: 57 900 ₽, 788 установок, CPI 93 ₽, на паузе с ~22.09. Дальше — не «пилот», а **вторая кампания** на починенной атрибуции.
2. **Baseline измерен** (Amplitude, 2 мес) — цифры ниже. Реклама разрешена после релизов 1.3.1+1.4.0.
3. **Директ подтверждён главным каналом**, бюджет владельца 10 000 ₽/нед.
4. **Аудит листинга Play:** рейтинг **3,43 (7 отзывов)** — главный конверсионный риск; название бренд-first — надо «Дневник…» (доказано отчётом поисковых запросов: 74% конверсий — слово «дневник»).
5. **Найдены баги:** share-ссылка онбординга ведёт на несуществующий пакет `com.den`; `deeplink_params_failed` летит почти на каждом открытии (`NOT_A_FIRST_LAUNCH` считается failed).
6. **Аудитория:** РФ 85%, русский 99%, масс-маркет устройства (Samsung/Redmi/Tecno/Realme), свежий Android. EN/iOS — не приоритет (подтверждено данными).
7. **Версионная фрагментация:** только 40% базы на 1.3.0, 60% на 1.1.0/1.2.0 — старый UX и риск SQLITE_FULL.

## Итоги сессии «Аналитика/стратегия» (06–11.11) — сводка для штаба

**Что сделано:** baseline и экономика (выше), свежий срез 11.11, аудит листинга Play, разбор 475 поисковых запросов Директа, профиль аудитории, научное обоснование категории, брейншторм 12 идей с решениями владельца. Детали — в треках ниже и `.agents/memory/den-analytics.md`, `den-growth.md`.

**Свежий срез 11.11 (vs 06.11):** DAU развернулся 13→20 (06–10.11, avg недели 14.3); habit retention микророст: D1 27.1 / D7 15.8 / D30 6.7 (n=773); воронка 77% стабильна; новые ~1.3/день без изменений. В проде замечены события новых фич (`summaries_opened`, `day_reply_shown`). **`deeplink_params_failed` всё ещё ~на каждом запуске → фикс 1.3.1 у пользователей не был: публикация ждёт сборки (EAS, владелец).**

**Стратегический каркас (решено на сессии):** ценность реальная, но отложенная (видна через 2–3 недели) → порядок рывка: удержание D7 → доверие к данным (бэкап) → рейтинг 3,43 → масштаб. Каждое улучшение retention дешевит «месячного» пользователя (1575 ₽ → цель ~800 ₽).

**Решения владельца по брейншторму 11.11 (блок «Брейншторм 11.11» в Трек 2):** одобрены закрытие дня (планка «только стильно»), вечерний пуш=вопрос дня, годовщины (скрыты до мая 2027, затем сюрприз), авто-капсула месяца, quick=mood-only + ввод из шторки (задачи → воскресная рефлексия), голосовой ввод, «свидетель дня» (ссылка живёт 1 день), витрина анонимных фраз (MVP без бэкенда), «Книга года» PDF-альбом (первый платный продукт, НГ), ML-инсайты (спайк с честным дисклеймером, предпочтительно без сырого текста), «интервью с собой» (тест внутри рефлексии до отдельного раздела). Отклонено: «фильм года». Онбординг-трио активации («восстанови вчера» + демо недели + обещание воспоминания) — в блоке 1.4.x.

- **Экономика сентябрьской кампании:** РСЯ CPA 32,5 ₽ (33,9k кликов) vs Поиск CPA 121,8 ₽ → **РСЯ в 3,7× эффективнее**. Цепочка цен: установка 93 ₽ → первая запись ~141 ₽ → «недельный» ~690 ₽ → «месячный» ~1575 ₽.
