# Дизайн-направление «День» (аудит по методике unslop)

> Методика: [unslop](https://github.com/heydamir/unslop) (Damir Sokolovsky, CC BY 4.0) —
> аудит на «slop», направление (характер, мир, цветовые моменты, фирменная деталь),
> правки проходами. Применено вручную: цель для аудита — веб-сборка
> (`expo export --platform web`) + скриншоты, нативные места — по коду.

## Характер

**«Вечерняя лампа и бумажный дневник», а не дашборд.** Мир продукта — тихий
вечерний ритуал один на один с собой. Тёплый свет, бумага, тишина. Не
клиническая неоновая мята на GitHub-тёмном — у приложений по шаблону нет лица.

## Что меняем (проходы)

1. **Color.** Мята `#5EE6A8` уходит с доминанты: цвет живёт только в шкале
   настроений (это те самые 1–2 момента, которые несут цвет). Фон — тёплый
   уголь вместо холодного `#06080B`. Все декоративные градиенты удаляются.
2. **Signature detail.** Фирменная деталь — **квадрат-пиксель** (мотив
   «Года в пикселях»): точки календаря, streak, выбор настроения. Выбранное
   настроение «зажигает» пиксель с мягкой пульсацией — награда сохраняется,
   меняется механика (неоновое гало `shadowRadius: 20` умирает).
3. **Type.** Заголовки, даты и цитаты — сериф с кириллицей (Spectral или
   PT Serif, финальный выбор после проверки глифов); Inter остаётся для UI.
4. **Icons/copy.** Эмодзи-статусы писем (🔒✉️📖) → Ionicons; «Запечатать 💌» →
   без эмодзи; ALL-CAPS микролейблы → sentence case (не более 1–2 на экран).
5. **Layout/details.** Плоские карточки (прощай `elevation: 20`), единая шкала
   радиусов 12/20 (прощай 28 на CTA), CTA — плоская заливка вместо
   `LinearGradient #1B6B4A → #0D2B1A`, кружки настроений — без градиента
   `#2A2E35 → #1A1D22`.

## Чего НЕ трогаем

- Эмодзи-иконки настроений — это контент, не украшение.
- Палитру ступеней настроений с CVD-обоснованием (`MoodPicker.tsx`).
- Тихий тон копирайта и существующие тексты (проход copy — только механика:
  регистр, эмодзи-статусы).
- Виджет — удалён из продукта (11.11), из дизайн-объёма исключён.

## Порядок экранов

1. **ShareCard** — виральный и ASO-ассет, лицо продукта вне приложения.
2. «Сегодня» + MoodPicker (пиксель вместо гало).
3. «Воспоминания» (streak-карточка, пиксель-мотив).
4. «Настройки» (sentence case, плоские строки).
5. Точки календаря → пиксель-квадраты.

## Палитра (целевая, уточняется на токенах)

| Роль | Было | Стало (черновик) |
|---|---|---|
| Фон | `#06080B` холодный | тёплый уголь ~`#0D0C0A` |
| Карточка | `#0D1117` | приподнятый тёплый тёмный |
| Акцент | `#5EE6A8` везде | только шкала настроений |
| Текст/рамки | без изменений | |

## Риски и контроль

- Регрессии: react-compiler (эксперимент включён), reanimated (пульсация
  пикселя), автотестов нет — проверка typecheck + скриншоты веб-сборки +
  ручной прогон на устройстве.
- Слепая зона аудита: нативные экраны оценены по коду — финальный проход
  делать по скриншотам реального устройства.
- ASO-скриншоты и креативы для Директа пересобираются только после
  утверждения направления владельцем.
